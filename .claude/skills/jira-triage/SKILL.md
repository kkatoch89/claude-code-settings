# Jira Triage

Use this skill when given:
- rough notes
- a feature ask
- a bug summary
- a Slack summary
- a technical direction that needs ticketization

## Goal

Produce a clear, scoped work item.

## Output format

### Title
### Description
### Scope
### Out of Scope
### Acceptance Criteria
### Dependencies / Risks
### Suggested Subtasks

## Supporting files
- references/acceptance-criteria-checklist.md
- commands/concise.md

## Constraints
- keep it implementation-ready
- do not invent missing requirements
- keep acceptance criteria testable
