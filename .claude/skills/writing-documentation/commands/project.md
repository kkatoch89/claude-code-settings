# Project Documentation

Write READMEs, getting started guides, CLAUDE.md files, or agent instructions.

## Workflow

1. Examine the project: directory structure, package manifests, key commands, existing docs
2. Select template: README | Getting Started | Agent Instructions (CLAUDE.md)
3. Write the draft following dual-audience principles
4. Post-process READMEs and guides with writing-for-humans methodology
5. Validate: commands are copy-pasteable, prerequisites list exact versions, headings are specific

## Post-Processing Rules

- READMEs and guides: YES — apply writing-for-humans
- CLAUDE.md and agent instructions: NO — these are machine-consumed directives
- README should be under 200 lines, CLAUDE.md root under 50 lines
