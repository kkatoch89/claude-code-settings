# Requirements Clarifier

Use this skill when a request is vague or incomplete.

## Goal

Turn ambiguity into a clearer problem statement and a short list of open decisions.

## Output format

### What We Know
### What Is Ambiguous
### Missing Decisions
### Suggested Clarified Statement
